WHY THIS FILE EXISTS
  Ten tags carry no signature of their own, and EIGHT OF THEM CANNOT. A lightweight
  tag is a bare ref with no object, so there is nothing for a signature to attach to
  -- not an oversight that can be corrected in place. v0.1.0 through v0.4.1 are
  lightweight. Re-creating them as signed tags would move what ten published releases
  point at while removing nothing: GitHub and every clone already hold the old refs.
  So they are attested here instead of being rewritten.

  v0.5.0 and v0.5.1 ARE annotated tag objects and could have been signed at creation.
  They were not. That is an oversight rather than a limitation, and the remedy for
  releases after this file is to sign the tag when it is made; this attestation is
  what remains available for the ten that already exist.

*** WHAT THIS DOES NOT PROVE -- READ THIS BEFORE RELYING ON IT ***
  It proves these names pointed at these commits WHEN THIS FILE WAS SIGNED, and the
  OpenTimestamps proof beside it fixes that moment in the Bitcoin chain.
  It does NOT prove they pointed there originally. If a tag had been moved before this
  file was written, nothing here would reveal it. This is weaker than a signed tag and
  is not a substitute for one; it is what remains available after the fact.
